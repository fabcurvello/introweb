# Introdução ao Desenvolvimento Web

> Repositório didático: exemplos e exercícios de HTML, CSS e JavaScript desenvolvidos em sala de aula.

## Acesse online

Site publicado no GitHub Pages: **[https://fabcurvello.github.io/introweb/](https://fabcurvello.github.io/introweb/)**

## Sobre o projeto

Coleção dos exemplos e exercícios das aulas de introdução ao desenvolvimento web, do primeiro "Olá, mundo" em HTML até manipulação do DOM com JavaScript. A página principal (`index.html`) é uma loja virtual de exemplo, com carrinho de compras que guarda os itens no `localStorage`.

## Contexto acadêmico

Exercício aplicado em sala de aula no **SENAI-RJ**.

## Estrutura do repositório

- `index.html`: projeto **Minha Loja Online** (cabeçalho, menu, promoções, produtos e contato).
- `exaulas/`: páginas de cada aula e exercício.
- `css/`: folhas de estilo de cada exercício.
- `js/`: scripts dos exercícios. Arquivos com `gabarito` no nome trazem a resolução sugerida.

## Conteúdos das aulas

- **HTML**: primeira página, links, listas, tabelas, imagens, vídeos e `iframe`, formulários e HTML semântico
- **CSS**: introdução, `position`, **Flexbox** (incluindo desafio de e-commerce), **CSS Grid** e responsividade, variáveis CSS e animações
- **JavaScript**: revisão da linguagem, objetos, manipulação do **DOM** (lista de filmes, playlist), formulário de feedback e sistema de gestão de alunos

## Tecnologias

- **HTML5**
- **CSS3** (Flexbox, Grid, variáveis, animações)
- **JavaScript** (DOM, eventos, `localStorage`)

## Como executar

Clone o repositório e abra `index.html` ou qualquer página da pasta `exaulas/` no navegador. Recomenda-se usar a extensão **Live Server** do VS Code.

```bash
git clone https://github.com/fabcurvello/introweb.git
```
